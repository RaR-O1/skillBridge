# SkillBridge Client

React (Vite) + TypeScript + Tailwind CSS + TanStack Query + Socket.io client.

## Design Tokens
- Primary: `#4B2FC4` (Indigo Purple)
- Success: `#1F8A47` (Emerald Green)
- Warning: `#F08A24` (Amber Orange)
- Blue: `#2F6FE4` (Royal Blue)
- Danger: `#D64545` (Crimson Red)
- Font: Inter (8px spacing grid, 8px button radius, 12px card radius, 44px minimum touch targets)

## Key Components
- `PriceAgreementCard`: Dual confirmation of agreed budget before status is assigned
- `PaymentNoteBanner`: Direct settlement peer-to-peer notification
- `PipelineBoard`: Recruiter applicant kanban
- `SkillChip`, `StarRating`, `StatusBadge`, `VerifiedBadge`
- `SessionScheduler`: Mentor booking with Google Calendar links
- `AIHelperSheet`: Editable drafts with "Why this suggestion" disclosure
- `ReportModal`: Flag disputes, payment default, and spam
